# 🔧 Arduino Sensor & Actuator Testing Library

A practical collection of Arduino, ESP32, ESP8266, robotics, sensor, actuator, and IoT experiments for hardware validation, embedded-systems learning, and STEM project development.

## ⭐ Featured Project

### 🎙️ ESP32 Voice Home Automation — SinricPro + Google Home

A portfolio-ready IoT demonstration where a single LED behaves as a smart-home device controlled by natural voice.

**Stack:** ESP32 • Arduino • Wi-Fi • SinricPro • Google Home • Embedded C/C++

```text
Voice
  ↓
Google Assistant
  ↓
Google Home
  ↓
SinricPro Cloud
  ↓
Wi-Fi
  ↓
ESP32
  ↓
GPIO 2
  ↓
LED
```

**Project:** [`ESP32_Voice_Home_Automation_SinricPro`](./ESP32_Voice_Home_Automation_SinricPro/)

**Highlights:**
- Natural voice ON/OFF control
- ESP32 Wi-Fi connectivity
- SinricPro cloud integration
- Google Home integration
- Safe low-voltage LED actuator
- Wi-Fi auto-reconnect
- Credential separation with `config.example.h`
- Portfolio-grade documentation
