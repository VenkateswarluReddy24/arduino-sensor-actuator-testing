# 🔧 Arduino Sensor & Actuator Testing Library

A practical collection of embedded systems, robotics, IoT, sensor, actuator, and ESP32 experiments for hardware validation and STEM demonstrations.

## 🌟 Featured ESP32 Project

### 🎙️ ESP32 Voice Home Automation — SinricPro + Google Home

A complete smart-home demonstration using an **ESP32 and a single LED**. Voice commands from Google Assistant travel through SinricPro to the ESP32, which drives the LED from GPIO 2.

**Demo command:**

> “Hey Google, turn on Demo Light.”

**Architecture:**

```text
Voice → Google Assistant → Google Home → SinricPro → ESP32 → GPIO 2 → LED
```

**Highlights**
- 🎙️ Natural voice control
- ☁️ SinricPro IoT integration
- 🏠 Google Home support
- 📱 SinricPro app backup control
- 💡 Single LED actuator
- 🔌 ESP32 GPIO 2 output
- 📟 Serial diagnostics
- 🧪 Safe, classroom-friendly low-voltage demo

## 📌 Overview

This repository contains practical testing and demonstration codes for commonly used sensors, actuators, microcontrollers, robotics platforms, and IoT systems.

These modules are used for hardware validation before integrating components into larger embedded and robotics systems.
